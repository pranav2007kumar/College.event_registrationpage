# Anokha 2026 Registration Portal (Light Theme)

A pure HTML, CSS, and JS web platform to preview the 2026 Tech & Sports festival registrations dynamically without reliance on external backend tooling. Includes state tracking and full-page scanning simulations. 

## To Run the Project
1. Copy the source files (index.html, style.css, script.js, and .png asset maps) to any computer.
2. In your terminal, navigate directly into the folder where you placed these files.
3. Start the application locally via a node server or python server using:

   python -m http.server 3000

4. Open your browser and navigate directly to:
   http://localhost:3000

Everything will run smoothly via the browser's local memory!
